# SeenIt

The published page of **SeenIt** — a personal Ukrainian-language movie/TV
tracker. Live at https://alvl-station.github.io/seenit/

This repository is a build artifact: `index.html` is generated and pushed
here by the deploy pipeline in the private **seenit-frontend** repo. Don't
edit it by hand — changes land through that pipeline and would be
overwritten by the next deploy.
